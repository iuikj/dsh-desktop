# [开源项目] dsh-desktop：把 DeepSeek Harness 的 Web 界面封装成原生桌面应用

## dsh-desktop

DeepSeek Harness（dsh）的 Web 界面默认要在浏览器里打开，窗口混在浏览器标签里，既没有独立的任务栏图标，也没有"原生软件"的感觉。

这个项目把它封装成了一个 Electron 桌面应用：双击即用、独立窗口、自动启动 / 自动安装后端服务，并且做了一套**和网页配色浑然一体的全自绘无边框标题栏**——标题栏和侧边栏同色连成一个 L 形整体面，内容区是左上角带圆角的"浮起卡片"，观感不像"网页套了个壳"。

### 核心特点

- **全自绘无缝标题栏**：彻底去掉 Windows 原生标题栏，标题栏底色实时跟随侧边栏颜色（亮/暗主题自适应）；`文件/编辑/视图/窗口/帮助` 纯文字菜单直接嵌进标题栏，左上角收起侧边栏，右上角自绘最小化/最大化/关闭
- **开箱即用**：启动时自动探测并拉起 `dsh web`；本机没装 DeepSeek Harness 时自动用 npm 安装（带进度日志）
- **像原生应用**：鲸鱼应用图标（多尺寸 ICO）、托盘图标 + 最小化到托盘、窗口位置记忆、端口冲突自动换端口、双击标题栏最大化
- **分发友好**：NSIS 安装器在安装阶段自动检测并安装 DSH 依赖；内置 electron-updater 自动更新；GitHub Actions 打 tag 自动出 Release
- **中英双语**：菜单跟随系统 locale，安装器 / 日志 / 提示都是中英双语

### 技术栈

Electron 43 · electron-builder · electron-updater · Node.js（用于拉起 dsh 服务）
